Why DANBOT?

A reaction bot that keeps you in the loop: one controller, clear state, nothing hidden.

  • One controller

    Your DS4 and DANBOT's reactions merge into one virtual Xbox controller, so the game never switches input devices.

  • Works from the screen

    DANBOT reads the same red and orange attack indicators you see, then answers through the controller.

  • Says what it will do

    The Active Behavior card spells out what holding LT will send before you press it.

  • No keyboard or mouse

    No hotkeys and no simulated key or mouse presses. Controller in, controller out.

  • Profiles that follow you

    Profiles sync with your account between PCs, and a conflict keeps both copies.

  • No admin rights to run

    Only the one-time driver setup needs administrator rights. DANBOT itself runs as you.

    Set up in five steps

    Driver setup needs administrator rights once. After that, DANBOT runs as a normal user.

    1. 01

      Install the drivers

      Install ViGEmBus, which provides the virtual Xbox controller, and HidHide, which hides your DS4 from the game.

    2. 02

      Hide your DS4

      In HidHide, hide the Sony controller and whitelist DANBOT.exe, not the game. Reconnect the controller. Moved the exe? Add it again.

    3. 03

      Start DANBOT

      Close DS4Windows and any other virtual-pad tool. Open DANBOT.exe, sign in and redeem your key.

    4. 04

      Check readiness

      The Dashboard should show Virtual controller: Ready, and Controller & Binds › Input bridge should report Source ON.

    5. 05

      Start the game

      Launch For Honor, or restart it, once the virtual controller exists. Then press Start bot.

    6. Requirements

      • Windows 10 or 11, 64-bit
      • A DualShock 4 controller
      • ViGEmBus and HidHide
      • WebView2, built into Windows

    Recommended game settings

    • FOV 81 and contrast 55
    • Shadows, motion blur, ambient occlusion and dynamic reflections off
    • Menu resolution matches the game render
    • Fullscreen or borderless, not windowed

    Then set the same resolution in Diagnostics › Calibration & overlay.

    Questions, answered

    Does DANBOT need administrator rights?

    Not to run. Installing the ViGEmBus driver and configuring HidHide need administrator rights once.

    Does it use my keyboard or mouse?

    No. The only input path is your DualShock 4, read over HID and merged into one virtual Xbox controller. There are no hotkeys and no keyboard or mouse input or output.

    Can I keep DS4Windows running?

    Close it, along with any other virtual-pad tool, before you start DANBOT. Otherwise the game sees a second controller.

    Do I need to install .NET?

    No. DANBOT.exe is a single self-contained file of about 50 MB. It needs the ViGEmBus driver and the WebView2 runtime, which Windows 10 and 11 already include.

    Where are my settings kept?

    Profiles, settings and telemetry live in %LOCALAPPDATA%\DANBOT, so you can move or replace the exe freely. Profiles also sync to your account; machine settings such as the hold button stay on each PC.

    What happens if I'm offline?

    DANBOT checks your license at sign-in and every 6 hours. Without a check it keeps working for up to 72 hours, never past the key's expiry date. After that it goes back to the license screen and a running bot pauses until the check succeeds.

    I moved to a new PC. What now?

    Each key covers a set number of PCs, one by default. If you've used them all, ask the DANBOT team to reset your PC slots.

    Is my password stored?

    No. It's sent over HTTPS and never saved. DANBOT keeps only a rotating session token, encrypted with Windows DPAPI for your Windows user.

    Is game automation allowed?

    Game automation can violate game rules or anti-cheat policies. Test responsibly, preferably in training or offline modes.
