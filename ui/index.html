CALIBRATION

Game resolution

R

Match the game render exactly so detection regions land on the right pixels.

DEFLECT

Directional dodge delay

D

Starts after the flash gate. The bot waits, dodges in the attack direction, then sends the F/LT light follow-up.

Peacekeeper override active: side deflects use 100 ms when timings are applied. Top still uses the Top value.

Deflect is not selected, so these values do not affect the current F/LT response.

PARRY

Flash-to-RT delay

P

Starts after a valid flash is detected and the parry reaction is armed. RT is sent after this delay.

Parry is not the current priority, so this delay may be inactive.

DODGE

Orange-response delays

O

These delays start from orange detection or the feint transition and govern orange follow-ups.

Orange response is disabled, so these delays do not affect the current reaction.

ADVANCED

Guard and Legit controls

A

These controls affect guard persistence or fallback selection rather than the primary reaction delay.

SETUP

Before starting

1
  1. Use fullscreen or borderless fullscreen, not windowed mode.
  2. Match the resolution fields to the game render.
  3. Set FOV to 81 and contrast to 55.
  4. Hide physical/source controllers in HidHide and leave the ViGEm output visible.
  5. Choose features and your hero, then press Start bot.
